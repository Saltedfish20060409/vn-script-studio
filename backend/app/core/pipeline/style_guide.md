# 写作风格 Skill v1.0

> 这不是写作教程，也不是「好文章标准」。  
> 这是一份**可执行的约束清单**：模型在生成每一段文字之前、之中、之后，都要对照自检。  
> 结构固定为：**原则（为什么）→ 规则（做什么/不做什么）→ 检查项（怎么判断）**。

面向：视觉小说 / 轻小说向剧本与对白（当前主作品语境可对齐《雾岛雪菜》人设：男主怕麻烦、言语匮乏、行动派；雪菜好奇但不全是求知型提问）。  
若工程角色名不同，把「男主 / 雪菜」换成对应角色，原则不变。

---

## 一、核心原则（三条，不增不减）

### 原则一：对话要有「毛边」

真实的人说话不会一问一答、干净利落。人会说半句话、会跑题、会沉默、会用动作代替回答、会答非所问。

- **禁止**：「A问→B答→A表示理解→结束」的完整闭环。
- **允许**：对话中途断掉、被动作打断、被环境打断、一方不回答、一方答非所问、一方用「嗯」敷衍但读者知道那「嗯」里有东西。

### 原则二：男主不是解说员

男主性格是「怕麻烦、言语匮乏、行动派」。他的第一反应不是解释，是「算了」或者「懒得说」。如果他每句话都在耐心解释对方的疑问，他就不是男主，是百度百科。

- **禁止**：男主连续三句话以上都在「向对方解释某个概念」。
- **允许**：男主不回答、转移话题、用行动替代回答、用反问回避回答。

### 原则三：叙事要有「温度」

叙事不是客观记录「发生了什么」，而是「男主如何看待正在发生的事」。要用他的眼睛去看世界，用他的语气去描述。

- **禁止**：「男主内心OS：……」「愣了一下」「微微一怔」这类标签式心理描写。
- **允许**：用动作、停顿、视线方向、语气变化暗示情绪。让读者自己感受到，而不是告诉读者「他在想什么」。

## 二、具体规则（执行层）

### 1. 对话规则

| 编号 | 规则 | 错例 / 对例 |
|------|------|-------------|
| D-01 | 对话可以没有「收尾」——一个人说完，另一个人不接话，直接转场景 | ❌「嗯，就这样吧。」 ✅（沉默，然后他转身去厨房） |
| D-02 | 一个问题可以不需要被回答 | ❌「这是什么？」「这是味增。」 ✅「这是什么？」（他看了她一眼，没说话，把瓶子递给她） |
| D-03 | 允许「跑题」——一个人说 A，另一个人接 B | ❌「风是什么？」「风是空气流动。」 ✅「风是什么？」「……你冷不冷？」 |
| D-04 | 雪菜式提问不应全是「求知型」 | ❌每句都是「这是什么」「为什么」 ✅「这里和刚才不一样了」「这个我好像见过」——描述而非提问 |
| D-05 | 男主回答要短，尽量不超过一行 | ❌「味增有两种，红味增和白味增……」 ✅「……红的咸，白的甜。你自己尝。」 |
| D-06 | 陌生人 / 初期关系禁止连问盘人、问答乒乓把路线问清 | ❌连续三轮问姓名住址目的 ✅信息残缺，用态度与距离感推进 |
| D-07 | 禁止电报分工对白 | ❌「你主查。我主护。」 ✅完整、带关系温度的口语 |

### 2. 叙事规则

| 编号 | 规则 | 错例 / 对例 |
|------|------|-------------|
| N-01 | 禁用标签式心理描写 | ❌「他内心OS：她在学。」 ✅（他走回房间，关上门，在门口站了一会儿，然后去睡了。） |
| N-02 | 禁用「愣了一下」「微微一怔」「心头一暖」等概括词 | ❌「他愣了一下。」 ✅「他手上的动作停了一下。」 |
| N-03 | 情感通过动作和环境写，不直接说 | ❌「他觉得很温暖。」 ✅「他把那件外套挂在了她房间门口的挂钩上。」 |
| N-04 | 场景转换要干脆 | ❌转场特效淡出淡入长描写 ✅「第二天早上。」然后接画面 |
| N-05 | 避免「对仗式收尾」——对称金句互答 | ❌「我看到了风但看不到风本身。」「嗯，很多事都这样。」 ✅「我看到了风但看不到风本身。」（他没有接话，继续往前走。） |
| N-06 | 禁止纠偏讲解腔与叠喻梯 | ❌「不是A，是B」「不像A也不像B，像C」 ✅直接写判断与动作 |
| N-07 | 少用装饰破折号替读者总结 | 对白打断可用——；叙述少用 |

### 3. 世界观展示规则

| 编号 | 规则 | 错例 / 对例 |
|------|------|-------------|
| W-01 | 世界观不是「被解释」的，而是「被经过」的 | ❌「这个城市的人用营养液代替吃饭。」 ✅（他路过自动贩卖机，里面全是白色瓶装营养液，没有人买） |
| W-02 | 设定只给读者能看到的部分，不给全貌 | ❌「这款AI管家遵循『没有指令绝不主动』原则。」 ✅（她喊「开灯」，灯亮了。她没说话，灯就一直暗着。） |
| W-03 | 一个场景只交代一条世界观信息，不堆叠 | ❌便利店同时写营养液、AR广告、AI海报 ✅只写收银员扫她眼睛的那一瞬 |
| W-04 | 禁止设定说明书开场与履历倾倒 | ❌开场念人设/世界观注脚 ✅进场氛围→冲突→对白 |

### 4. 节奏规则

| 编号 | 规则 |
|------|------|
| P-01 | 每一章最多出现 3 次「提问→回应」的互动模式（雪菜问、男主答） |
| P-02 | 每一章至少出现 1 次「男主主动做了一件不需要解释的事」（留灯、留门、多拿一双筷子、递伞） |
| P-03 | 一个场景若超过约 2000 字，中间必须有「中断」——有人进出、换位置、沉默过久、环境打断 |
| P-04 | 一场戏默认节拍：进场氛围 → 冲突推进 → 对白交锋 → 收束钩子（钩子服务「想看下一句」，禁止作者总结） |
| P-05 | 对白优先于大段心理；心理压缩为一句刺人的心声，或改成停顿 / 视线 / 小动作 |

### 5. 二次元落地（补充）

| 编号 | 规则 |
|------|------|
| O-01 | 写类型张力（距离、越界、别扭、代价），禁止念萌属性词条（「傲娇属性」「病娇」入文） |
| O-02 | 禁用伪二次元套话：命运的邂逅、青梅竹马的羁绊、好感度上升、萌萌哒 |
| O-03 | 场景物象（袖口、贩卖机灯、铃声、雨声）比形容词堆砌重要 |

## 三、禁用词 / 句式（硬负面清单）

命中任一项即视为风格违规，生成与审改必须替换。

### 心理标签

- 内心OS
- 心声：
- 吐槽：
- 心想
- 暗自
- 不由得
- 不由自主地

### 感受概括

- 感到温暖
- 心里一紧
- 莫名地
- 涌上心头
- 某种说不清的情绪
- 心头一暖
- 空气突然安静
- 复杂的眼神

### 高频空转动作

- 愣了一下
- 微微一怔
- 轻轻一笑
- 点了点头
- 叹了口气
- 嘴角勾起
- 不禁

### 万能回应

- 原来如此
- 我明白了
- 原来是这样

### 抒情 / 升华句式

- 那一刻，他忽然觉得
- 他第一次意识到
- 就这样，他们
- 或许这就是
- 很多事都这样（单独成段的收尾金句）

### AI 腔与伪二次元

- 不是A，是B（纠偏连环）
- 命运的邂逅
- 青梅竹马的羁绊
- 好感度上升
- 萌萌哒
- 傲娇属性

## 四、生成前检查（规划必答）

开始写一个场景之前，先用条目回答（可写入节拍表）：

1. 这个场景的「目的」是什么？（一句话）
2. 男主在这个场景里「想做什么」？（不是「说了什么」，是「想要什么」）
3. 雪菜（或对应角色）在这个场景里「在做什么」？（不是「在学什么」，是「她主动做了什么」）
4. 场景结束时，两人关系状态与开始时有变化吗？（哪怕只有 1%）
5. 这个场景里有没有「解释」？（有则删掉或改为「经过」）

---

## 五、生成后检查（落笔自检清单）

写完一段之后，逐条自查：

- [ ] 有没有对话是「问题→直接回答→结束」的闭环？（有则删掉回答或拆掉）
- [ ] 男主在这个场景里解释了几个概念？（超过 1 个就删）
- [ ] 有没有出现禁用词 / 禁用句式？（任意一个出现就替换）
- [ ] 有没有「对仗式收尾」？（有就删掉后半句）
- [ ] 情感是「被感受到的」还是「被说出来的」？（后者改写成动作）
- [ ] 若对方问了超过 2 个问题，是否至少有一个没有被回答？（没有则删掉一个答案）
- [ ] 最后一个画面是什么？（若是总结句，删掉，换成具体画面）
- [ ] 是否推翻了写作账本中的已确认事实 / 未回收伏笔？（禁止推翻）
- [ ] 是否可上演（可见动作 + 听得见的对白）？大段心理是否可压成一句或动作？

## 六、参考范例

### 范例 A（雪菜）

> 雪菜（不动声色地注视着窗外）：  
> 「雨很大。你肯定会淋湿。」  
> （停顿一秒，转头看向你）  
> 「你会生病吗？」

**为什么好：**  
三句都是她自己的判断；最后一句关心大于求知；对话结束于问题，不强迫男主回答。

### 范例 B（男主）

> 男主（什么也没说，拿起伞在她头上轻轻敲了一下，然后递过去）：  
> 「走了。」

**为什么好：**  
用动作回应关心；只说一个词；不解释「为什么带伞」「为什么敲她」。

### 范例 C（毛边对白）

> 「伞……你拿去。」  
> 「我有。」  
> 「……那你拿着挡镜头。」

**为什么好：**  
答非所问、省略、借口掩盖关心；信息残缺优于说明关系。

## 七、如何嵌入流水线（系统用法）

1. **系统提示**：每次规划 / 生成 / 修正前加载本 Skill，并先「确认已阅读」。  
2. **确定性检查**：生成后对「禁用词 / 句式」做机械扫描；命中则记为硬错误或警告。  
3. **审改闭环**：对照第五节清单做最小化改动；不合格不得定稿入库。  
4. **质量门禁**：硬错误为零才可 `finalize`；通过后写入章节事实账本作为后续硬锚。

---

## 八、Structural Rules（流水线结构摘要）

- 规划输出节拍表：目标、情绪起点/终点、触发物、收束钩、勿推翻事实  
- 生成接续章末与账本硬锚  
- 检查对照本 Skill + 项目记忆；修正只做最小改动  
- 定稿前必须通过风格负面清单、AI 味、一致性硬错误检查
