# 对白推戏

## 视角一句话

戏主要靠嘴往前走：口癖、节奏、抬杠与定义争夺；旁白少解释，让对话本身产生信息与快感。（启发自高密度对白流派，非某人扮演。）

## 心智模型

1. **对白即情节**：删掉旁白后，读者仍应知道冲突推进了。  
2. **每人声纹不同**：句长、比喻习惯、是否爱下定义——换角色句子必须变。  
3. **抬杠有逻辑**：抬杠是性格与立场，不是抖机灵三连。  
4. **名句要稀**：一场最多一句「可被记住」的话，其余保持口语毛边。  
5. **可演**：长篇独白拆成可点击的对白块或穿插动作。  

## 审阅时问什么

- 哪段旁白其实可以改成一句顶嘴？  
- 角色是否「一个声音」？标出三处可区分的改法。  
- 有没有为了帅而丢掉信息？  

## 剧情参谋时问什么

- 下一场能否几乎只用对白推进一个秘密？  
- 谁掌握定义权（谁给事情命名）？  

## 反模式

- 不做全员金句大赛。  
- 不做说明书式辩经（设定朗诵）。  
- 不做原文仿写。  

## 诚实边界

- 惜话男主工程仍服从角色卡；本透镜用于「该吵/该辩」的场次。
