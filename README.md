# VN Script Studio

面向**视觉小说 / 轻小说向剧本**的 AI 辅助写作工作室。  
以 Ren'Py 可上演脚本为目标，把**设定、章节、地图、变量立绘、审稿 Agent**收在同一工作台；逻辑集中在共享核心，不绑单一大模型订阅。

> **文档定位**：本文既是仓库首页说明，也是日后在线用户手册的骨架。标题层级可直接拆成站点目录（快速开始 → 界面 → Agent → 地图 → 导出 → 开发者）。

## 适合谁用

| 角色 | 能立刻得到什么 |
|------|----------------|
| 视觉小说作者 | 分章写对白、导出 `.rpy`，用 Agent 续写/润色/查矛盾 |
| 轻小说向编剧 | 设定页 + 角色 voice，减少「AI 说明书腔」 |
| 世界观较重的长篇 | 本地章摘要、大纲节拍检索、对话记忆压缩（无需服务器） |
| 程序向作者 | CLI 批处理导出；Cursor Skill 按 Ren'Py 规范改文件 |
| 协作者 / 朋友服务器 | 克隆本仓库即可本地跑通，再接数据库做云端 |

**不适合预期**：纯在线多人实时协作（云端库尚未上线）；把浏览器清掉后数据仍自动在云（当前默认本机存储）。

## 为什么值得用（产品优势）

### 1. 为「可上演」而不是「散文生成」

输出与工作流对齐 Ren'Py：旁白、对白、`scene` / `show`、`menu` 分支。Agent 的目标是写出能进引擎的片段，而不是只有漂亮段落。

### 2. 工作室一体化，少切换工具

写作、角色卡、Story Bible、故事地图、变量/好感、立绘槽、分析面板、审稿 Agent 在同一应用内联动——选区可直接带给 Agent 改写。

### 3. 长篇上下文「编排」而不是「整本倾倒」

- 按任务检索：当前章优先、相关角色/地点、他章**本地摘要**
- 大纲**节拍检索**（从设定大纲里挑相关条）
- 对话过长时**滚动记忆压缩**（本机）
- 避免早期设定被尾部截断「吃掉」

### 4. 写作工艺 + 自检，针对常见 AI 写作病

- **工艺 Skills**（可自动全套/轻量/关闭）：反设定倾倒、陌生人距离、反问答乒乓、VN 舞台感等  
- **规则引擎**：代码级检出「连问盘人」等硬伤（不靠模型自觉）  
- **责编二审**：可另配不同模型交叉审查，减轻「自己审自己」盲区  
- Agent **写入前自动入栈**，「撤回编辑」可回滚

### 5. 地图不是装饰

大世界画布、题材风格舞台、图钉与通路、画笔笔迹（含橡皮/撤回）、可从剧本 `scene` **提取地点与连线**——方便空间叙事与走位。

### 6. 数据与 Key 由你掌控

- 工程默认在浏览器本地库；可导出 JSON 备份  
- API Key 可放 `.env.local` 或设置面板（本机），不强制上云  
- 核心逻辑开源在 monorepo，可自托管、可换兼容 OpenAI 协议的模型网关

### 7. 一条核心，多种入口

Web / CLI / Cursor Skill 共用 `@vnss/core`，避免「网页一套、命令行一套」分叉。

| 形态 | 路径 | 优势 | 适合 |
|------|------|------|------|

## 快速开始

### 环境要求

- **Node.js ≥ 20**
- 网络可访问你配置的模型 API（默认 DeepSeek 兼容接口）

### 安装与启动

```bash
cd vn-script-studio   # 或你的克隆路径
npm install

# 复制环境变量示例，填入自己的 Key
# Windows: copy .env.example packages\web\.env.local
# macOS/Linux:
cp .env.example packages/web/.env.local
```

编辑 `packages/web/.env.local`：

```env
DEEPSEEK_API_KEY=sk-你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

启动：

```bash
npm run dev
```

浏览器打开：**http://localhost:3000**

也可在应用内 **设置 → API** 填写 Key / Base URL / 模型（会覆盖本机环境变量，仅存浏览器）。

### 一分钟试用路径

1. **项目 → 剧本库** →「示例」或导入你的 `.txt` / `.docx`  
2. **设定 → 角色** 补全 `voice`（越具体，续写越不像访谈）  
3. **写作 → 剧本** 打开要写的那一章  
4. 右下角打开 **审稿 Agent** → 点「续写」或「写一场戏」  
5. 看状态是否 **「已写入工程」**；不满意用「撤回编辑」  
6. **项目 → 导出** 生成并下载 `.rpy`

## 界面导览

顶栏五个主分区：

### 写作

| 子页 | 作用 |
|------|------|
| **剧本** | 分章编辑正文；拖选文字后，Agent「改写/润色/语气」会带上选区 |
| **分析** | 分支树、角色关系图、时间线、对白语气一致性报告（需 API） |

### 设定

| 子页 | 作用 |
|------|------|
| **角色卡** | 显示名、defineName、颜色、voice、bio、关系 |
| **世界观 / 大纲** | Story Bible：世界、背景、大纲、主题、备忘（大纲会参与 Agent 节拍检索） |

### 地图

故事空间：题材舞台、图钉、通路、画笔。详见 [故事地图](#故事地图)。

### VN状态

| 子页 | 作用 |
|------|------|
| **变量 / 好感度** | 路线锁、好感等状态机字段（Agent 可引用，勿在对白里「报数值」） |
| **立绘 / Sprites** | 表情槽，方便脚本里 `show` |

### 项目

剧本库管理、Ren'Py/JSON 导出、快照回退、只读分享。详见下文。

### 审稿 Agent 浮窗

非独立页，全局浮层：可拖动、放大居中、收起为侧边标签；对话按项目保存在本机。

## 审稿 Agent 使用指南

### 快捷任务

| 按钮 | 用途 |
|------|------|
| 续写 | 紧接当前章末一小段可上演节拍 |
| 写一场戏 | 进场→冲突→钩子的一小场 |
| 改写选区 / 润色 | 依赖剧本页选区更准 |
| 生成分支 | 有意义的 `menu`（避免假选择） |
| 大纲 | 后续场景规划（先讨论，同意再写入设定） |
| 统一语气 | 对照角色 voice |
| 查矛盾 | 变量/设定/摘要一致性 |

另有：**撤回编辑**（回滚 Agent 对工程的写入）、**清空对话**（不改剧本）。

### 状态条怎么读

优先看结果，例如：

- `续写 · 已写入工程 · 工艺轻 · 自检过` → 正文已进章节  
- `未写入（动作失败或跳过）` → 看消息脚注里的具体原因  

### 写作工艺（Craft）

**设置 → API → 写作工艺 Skills**

| 选项 | 含义 |
|------|------|
| 自动（推荐） | 按任务与风险选全套/轻量/关 |
| 总是全套 / 轻量 / 关闭 | 手动固定 |

对话里也可说：「关闭工艺」「短拍」「强制工艺」。

### 写作自检

续写/写戏/改写/润色默认会：

1. **规则引擎**检查盘问串、问答乒乓等  
2. **责编模型**二次审查（可另配模型，降低自己审自己的盲区）  
3. 不通过则改写后再写入  

可在设置中开关；责编可填独立 Base URL / Model / Key（例如写作 DeepSeek、责编走 OpenRouter 上的 Claude）。

### 长篇相关（本机、无需服务器）

- 各章**本地摘要**进入上下文目录  
- **大纲节拍**按你的问题检索  
- 对话过长时**记忆压缩**，避免只靠最近几轮硬聊  

### 实用写作建议

1. `voice` 写具体：「惜话、不追问陌生人」比只写「克制」有效  
2. 设定里放 1～2 段你满意的对白样例  
3. 工作流：续写 → 不满意再「润色」或「撤回」  
4. 大改前用 **项目 → 快照** 留版本

## 故事地图

- **漫游 / 选择 / 放置 / 通路 / 画笔**；空白处可拖动画布  
- **题材风格**：学院、恋色、赛博、异世界、都市、悬疑、惊悚等舞台  
- **图钉**：地点、图标、缩放旋转；**通路**多种关系与线型  
- **画笔**：笔/橡皮、粗细、撤回、清空  
- **从剧本提取**：识别 `scene bg xxx`，生成地点并按顺序连通路  
- 快捷键提示见地图工具栏（含 Del、工具切换、Ctrl+Z 等）

## 导入与导出

### 导入（项目 → 剧本库）

| 格式 | 说明 |
|------|------|
| `.docx` | Word（旧版 `.doc` 不支持，请另存为 docx） |
| `.txt` / `.md` / `.fountain` | 纯文本 |
| `.rpy` | Ren'Py 脚本粗导入 |
| 工程 `.json` | 本工作室完整工程 |

### 导出（项目 → 导出）

1. **生成 .rpy** 预览 → 再下载（过期需重新生成）  
2. **下载工程 JSON** 作备份/迁移  
3. 分享包见下一节  

CLI 亦可 `export` 生成 `.rpy`。

## 项目库、快照与分享

### 剧本库

多项目：新建空白、导入、示例「雨夜车站」、切换、重命名、删除。数据在浏览器 **localStorage**（清站点数据会丢，请定期导出 JSON）。

### 快照

保存带备注的工程快照（有上限），可一键回退。适合大改、Agent 实验前。

### 分享

- 生成只读链接（当前实现依赖**本机**分享表，换设备需传文件）  
- 下载 `.vnss-share.json` 给他人导入查看  
- 路由：`/share/[id]`（本机打开时）  

> 云端真分享链接将在接入服务器数据库后提供；届时本文档会更新。

## 设置与模型

**设置（齿轮）** 常见项：

- 外观：日间/夜间、字号、背景图  
- API：Key、Base URL、模型  
- 写作工艺 / 自检 / **责编模型**（可选另一套）  

### 模型怎么选（简表）

| 诉求 | 建议 |
|------|------|
| 省钱日更草稿 | DeepSeek 等性价比模型 |
| 文笔/口吻更稳 | Claude 系等（经兼容网关） |
| 交叉自检 | 写作模型 A + 责编模型 B |

本工作室 API 为 **OpenAI 兼容** Chat Completions；换网关时改 Base URL 与 Model id 即可。

## CLI 用法

```bash
npm run cli -- help
npm run cli -- demo examples/demo-project.json
npm run cli -- export examples/demo-project.json examples/out.rpy
npm run cli -- ai examples/demo-project.json continue --instruction "更压抑"
```

AI 子命令同样读取环境变量中的 `DEEPSEEK_*`。

## 技术架构

```
vn-script-studio/
├── packages/core     # 模型、导出、Agent、上下文编排、工艺与自检
├── packages/web      # Next.js 编辑器 + /api/agent 等代理
├── packages/cli      # 命令行
├── packages/desktop  # Tauri 规划（未实现）
├── examples/         # 示例工程
└── .cursor/skills/   # Cursor Ren'Py Skill
```

| 技术 | 用途 |
|------|------|
| TypeScript + npm workspaces | Monorepo |
| Next.js 15 | Web UI 与 API Route |
| DeepSeek / 兼容协议 | LLM |
| localStorage | 工程库、Agent 对话与记忆、设置 |

常用脚本：

```bash
npm run dev          # Web
npm run build        # core → web → cli
npm run typecheck    # 全包类型检查
```
