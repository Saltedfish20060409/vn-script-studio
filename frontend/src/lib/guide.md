## 快速开始


> 注册→验证→建项目→写第一段→导出（5 分钟上手）



**① 注册并验证** 打开网站 → 右方"注册" → 填用户名、邮箱、密码 → 去邮箱点验证链接 → 回到页面登录。收不到邮件？检查垃圾箱，或点"重发验证邮件"。

![image.png](/guide/01-01.png)

**② 建一个项目** 登录后点『新建剧本』，取个名字（比如《雨夜车站》）就能开始。想从已有稿子起步？进入项目页→剧本库点"导入文件"，支持 Word / TXT / Markdown / Ren'Py。

![octlb4yu.png](/guide/01-02.png)

**③ 写第一段** 回到写作页，不需要任何格式知识——直接写：

（雨夜的站台，广播声断断续续。）



林夏：……你还记得这条路吗？

![image.png](/guide/01-03.png)

点击文本框上方“RPY”可以换成 Ren'Py 脚本，两份互不干扰。

**④ 让 Agent 搭把手** 右侧点开"审稿 Agent"，说一句"帮我把林夏登场这段改得更细腻"——它读章节、给意见、按你的要求改写，不满意可以撤回。

![image.png](/guide/01-04.png)

**⑤ 导出成稿** 写累了？右上角或项目页"导出"一键生成 Word / Markdown；要上演了，切到 RPY 导出 .rpy 直接进 Ren'Py试用。

![image.png](/guide/01-05.png)

## 登录页—— 从这里开始


**① 登录（已有账号）** 在"登录"标签下，输入用户名或邮箱 + 密码 → 点"登录"按钮即可进入。用户名和邮箱二选一都行，用哪个顺手填哪个。

- 登录失败？先看页面提示：密码错了就重新输入，账号未验证就去邮箱点验证链接，都没问题仍登不上可以走"找回密码"重置。

**② 注册（新用户主流程）** 点击卡片上的"注册"标签 → 填写用户名、邮箱、密码和确认密码 → 点"注册并发送验证邮件" → 去邮箱点验证链接 → 返回页面登录。

- 收不到邮件？先看垃圾箱，如果没有再点"已注册但未验证？重发验证邮件"。

- 邮箱务必填常用的那个——后续登录、收验证邮件、找回密码都靠它。

![image.png](/guide/02-06.png)

**③ 找回密码** 忘记密码？切到"忘记密码"标签 → 输入注册邮箱 → 收到重置链接 → 按提示设新密码。和验证邮件同一套通道，如果没看到同样先查垃圾箱。

![image.png](/guide/02-07.png)

**④ 右上角 · 更新公告** 页面右上角的 📢 公告 按钮，是官方动态的窗口：新功能、模型变更、重要通知都会放在这里。偶尔点开看看，不错过更新。

![image.png](/guide/02-08.png)

![image.png](/guide/02-09.png)

**⑤ 底部链接**

- 使用指南：遇到问题先来这里，多数答案在里面。

- 隐私政策 · 服务条款：数据怎么用、你能享受什么权利，白纸黑字写清楚。开始创作前值得花两分钟读完。

**⑥ 看板娘的小彩蛋（非必要）** 标题旁的看板娘不是摆设——点一下她会换表情和旁白。写作间隙来两下，心情会好一点。（台词会轮换，欢迎都点一遍。）


## 工作台（项目页）


登录后第一眼看到的就是工作台。快速开始只是带你把项目建出来，这里把容易漏掉的小功能都过一遍。



### 顶栏，藏着不少开关

![image.png](/guide/03-10.png)

1. **标题随手改**：顶栏里的作品名本身就是输入框，点一下就能改，不用进任何菜单。改完自动保存。

2. **「专注」与「审稿」：**写稿时顶栏会出现「专注」按钮（快捷键 `Ctrl+\`），点了全屏只留稿子，适合一口气写长段落，再按一次退出；「审稿」是审稿 Agent 的常驻入口——如果你把右下角的浮动小窗拖丢了或关掉了，点它就能找回来。

3. **「更多」菜单：**新建剧本、导入文件、保存章节、导出、帮助 / FAQ、协作都在这里（手机上顶栏放不下，也都收进了「更多」）。

4. **导出按钮跟着****写作页****走：**你现在在看剧本稿，顶栏就显示「导出 .docx」；切到 RPY 稿就变成「导出 .rpy」，永远导出的是你眼前这份。



### 剧本库，卡片上都是小操作

![image.png](/guide/03-11.png)

5. **三种建项目方式：**

①空白剧本从零开始；

②「示例《雨夜车站》」载入一个完整成品，适合拆开看结构；

③或从模板区挑一个题材（日常、悬疑、异世界……），几秒就有一章能写的内容，角色卡和世界观都给你搭好了。

6. **导入已有文件：**支持 `.docx / .txt / .md / .rpy / 工程 .json / .fountain`，Word 里的旧稿、别处写的剧本都能直接拖进来变成新工程。

7. **卡片四个按钮 + 两个隐藏动作：**打开 / 重命名 / 复制 / 删除。想在同一世界观下开新篇？点「复制」立刻得到一份独立副本，改坏了也不心疼原稿。还有两个隐藏动作：双击标题直接进入改名（回车确认、Esc 取消）；想留个底，复制或导出都行。删除有二次确认，且至少保留一个剧本。

8. **空状态也不空：**一个项目都没有时，工作台会直接给你「空白剧本」和「示例《雨夜车站》」两个按钮，不会让你对着空白页发呆。



### 容易被忽略的全局小功能

#### 效率与便捷

9. **工作台记得你上次的位置：**上次打开的项目、章节、页签、侧栏开关，刷新或重新登录后都会自动回到原处，不用每次重新找。

#### 趣味互动

10. **桌宠：**屏幕上的 Q 版小人可以拖动摆放，点击有反应、双击摸头、右键有菜单（回到编辑器 / 缩到角落 / 隐藏桌宠）。不想要了在设置里关掉。（目前是AI组出来的简陋版，后面可能更新立绘加新功能）

![image.png](/guide/03-12.png)

#### 写作氛围

11. **底部音乐条：**常驻在所有页面底部，可单曲循环/顺序播放/随机播放，点『＋ 添加』搜网易云 / 酷狗 / B站 的歌，还能粘贴 LRC 歌词滚动显示。注意：听歌用的 Cookie 只存在你自己的浏览器里，不会上传。

![image.png](/guide/03-13.png)

#### 外观与进阶设置

12. **点击特效：**点击空白处会有赛璐璐圆环 + 粒子的小动画，纯视觉不挡操作，输入框里不会触发；不喜欢的在设置里关。

13. **装成 App：**支持 PWA 的浏览器（Chrome / Edge，手机电脑都行）会弹「安装为应用」提示，装好后像原生 App 一样用，还能离线打开写作页。

14. **设置齿轮：**左下角齿轮里能换日间 / 夜间主题、全局字号；「背景」页可以导入图片铺满工作台，拖动取景、调缩放 / 透明度 / 暗角，面板玻璃跟着变色；「模型」页填你自己的 API Key（可选择账号存储或本机存储，详见「设置」章节），还能看今日 / 累计用量。

![image.png](/guide/03-14.png)

#### 协作与版本管理

15. **协作：**顶栏「协作」/项目成员页邀请成员当编辑或只读观众，主人可以改角色、移除成员；两人同时写同一章会看到锁，批注显示在章节下方。

![image.png](/guide/03-15.png)

16. **快照与只读分享（项目 → 快照 / 分享）：**大改稿之前存一份快照（可写备注），写砸了「回退到此」一键还原，还能「对比当前」看改了哪些字；「生成并复制链接」把设定摘要发给画师、配音看，随时可撤销。

![image.png](/guide/03-16.png)

1. **长程记忆：**章节多起来后，在项目页点「归档长程记忆」，会把每 10 章压成一段连续性摘要；归档后审稿 Agent 自动带着最新摘要写，不怕忘掉前文。




## 写作编辑器（写作页）


写作页是你每天待得最久的地方（大概）。这篇把编辑器里的功能挨个过一遍——很多藏得深，但知道了会顺手很多。建议先扫一遍布局，再按自己的写作习惯挑着看。



**先认布局**

1. 顶部是篇章条：一排章节标签就是你的目录，点哪个就进入哪一章写作；旁边「+ 章」可以新建章节，「删章」删掉当前章。章节名直接在工具栏的「章节名」输入框里修改即可。

2. 「剧本」和「分析」两个子页：默认在「剧本」里写正文；分析当前章节的结构，详见「写作分析」章节。切换时编辑器会自动保存当前内容，不用手动点。



**两种写法，一份稿子两个版本**

3. **剧本模式（默认）：**用自然语言写，旁白直接写，对白写成「林夏：……」的格式。这是给人看、给 AI 分析的稿。

![image.png](/guide/04-17.png)

4. **RPY 模式：**切到「RPY」就是 Ren'Py 脚本——旁白用 `"……"`，对白用 `角色名 "台词"`。两份稿互不覆盖，切来切去都在。想省事就点「根据剧本生成」，AI 把当前章的自然语言稿转成能跑的 Ren'Py 脚本。

![image.png](/guide/04-18.png)

5. **过期提示：**你在剧本模式又改了内容，回到 RPY 时工具栏会提示「剧本已改，RPY 可能过期」——提醒你再生成一次，别拿着旧脚本去试玩。

![image.png](/guide/04-19.png)

**写的时候，编辑器的隐形帮手**

6. **地点自动高亮：**你在「地图」里设定过的地点名，会像荧光笔一样在稿子里标出来；用鼠标点一下某个高亮地点，直接跳到地图页定位到它，改设定不用来回翻。

7. **语音输入：**工具栏的 🎤 按钮支持中文听写，点一下开始说话、再点一下停止，转写结果插到光标处。懒得打字时很好用（需要浏览器支持语音识别）。

8. **自动保存：**你停笔一两秒，稿子就自动提交保存，不需要手动点任何按钮。顶栏「更多 → 保存章节」是留给强迫症的（或者想确保此刻落盘时用）。

9. **改稿对照：**调用「审稿」Agent 让它给当前章节提修改建议，Agent 生成改稿草稿后，工具栏会出现「改稿对照」按钮——打开后左右对比原稿和改稿，满意就「写入」，不想要就「丢弃预览」。刷新页面后草稿还在，不会丢。



**写完想看看效果**

10. **▶ 试玩本章：**稿子下方的大按钮，以视觉小说的方式试玩当前章节，选项分支可以真的点。注意：试玩读的是 RPY 稿——如果你只在剧本模式写了自然语言，它会提醒你先「根据剧本生成」或手写脚本，然后自动帮你切到 RPY。

11. **专注模式（****`Ctrl+\`****）：**顶栏「专注」按钮，进入全屏只留稿子，界面自带正计时 / 倒计时番茄钟，适合一口气写完一个段落；再按一次 `Ctrl+\` 或 Esc 退出。底部的音乐条会被遮住，但音乐会继续放。

![image.png](/guide/04-20.png)

**跟别人一起写**

12. **批注在章节下方：**写作页往下滚就是批注区，可以给当前章节留言讨论，适合和合作者来回对戏。

13. **协作锁：**如果成员正在编辑同一章，顶部会显示「某某正在编辑本章（锁至 …）」——这时候先别改，等锁释放，避免互相覆盖。



以上就是写作页的主要功能。刚开始不用全记住，写的时候需要哪个再回来查就行。如果是第一次用，建议先从「剧本模式」开始写，熟悉后再尝试 RPY 脚本和试玩。


## 设定构建（设定页）


设定构建页用来搭建作品的底层信息。底栏有四个页签，分别管理不同层面的设定：「设定」填写角色与世界观，「角色工坊」打磨角色口吻，「地图」可视化故事地点，「VN状态」配置 Ren'Py 变量与立绘。设定写得越完整，AI 助手写稿和审稿时越懂你的作品。



### 「设定」页：角色、世界观与参考卡

1. **角色卡**：每个角色一张独立卡片，包含以下字段：

    - **显示名**：角色在作品中的名字

    - **Define 名**：Ren'Py 脚本中引用该角色的英文变量名，只能使用字母、数字和下划线

    - **颜色**：角色对白在脚本中的高亮色

    - **语气**：角色的说话风格

    - **简介**：角色背景与核心设定

    - **人物关系**：与其他角色的关联

![image.png](/guide/05-21.png)

2. **世界观 / 大纲**：以下内容会**原样进入 AI 上下文**，Agent 写稿和审稿时都会带着这些设定，请尽量写清楚：

    - **Logline**：一句话概括故事核心

    - **类型 / 题材**：作品的类型与题材标签

    - **世界观**：故事所处世界的基本规则

    - **故事背景 / 前情**：故事开始前发生了什么

    - **大纲 / 节拍**：故事的整体走向与关键节点

    - **主题 / 基调 / 禁忌**：作品想表达的主题、整体氛围与不能碰的红线

    - **其他备忘**：需要提醒 Agent 的其他事项

![image.png](/guide/05-22.png)

3. **设定卡（写作参考卡）**：给 Agent 喂"套路怎么做"的地方，收藏的卡会在 Agent 写作时**作为参考注入上下文**。

    - **手动添加**：填写参考条目，按行写清"要这样做 / 不要这样做 / 可演节拍"

    - **搜索萌娘百科**：输入关键词后直接回车搜索，从结果中挑选条目「收藏到本作」

    - **查看 Agent 注入**：右上角按钮，预览当前 Agent 实际能看到哪些设定卡

    - **灵感清单**：内置的离线条目库，可直接选用

![image.png](/guide/05-23.png)

### 「角色工坊」：把角色的说话风格定下来

4. 角色工坊不是普通聊天机器人，目标是产出**思维包**（角色口吻与思维模式的数据包）。分三步走：

    1. **定声音**：生成三组对白，选最像角色的一句入库。务必换多个场景收集（被误解、别扭关心、面对权威……），单场景语料会片面。还可以用「长场次」或「扮演采访」加厚语料。

    2. **出思维包**：语料达到以下任一门槛即可合成：

        - 短正例 ≥ 6 条，且覆盖 ≥ 5 个不同场景

        - 长场次 ≥ 2 场

        - 角色台词总量 ≥ 800 字

    3. **试聊排练**：有思维包后，可以和角色对话，或让两个角色互聊，验收口吻是否到位。

![image.png](/guide/05-24.png)

### 「地图」：故事地点的可视化

5. **五种编辑工具**：

    - **漫游**：拖空白处平移，滚轮缩放

    - **选择**：框选或 Shift+点击切换选中，可多选拖动

    - **放置**：单击放置一个地点节点

    - **通路**：先点起点再点终点，连线样式可选

    - **画笔**：手动画线，可切橡皮（快捷键 E），Ctrl+Z 撤回

6. **智能提取地点**：工具栏的「智能提取地图」可从当前剧本自动提取地点（综合 scene 标签、对白 / 设定词典与模型语义），提取结果可逐条确认；「仅 scene」模式只按 scene 标签提取。空地图时也有同样的提取入口。

7. **与写作联动**：在「地图」里设好的地点名，写作页会自动高亮；点击稿子里的高亮地点，直接跳到地图定位——改设定不用来回翻页。

![image.png](/guide/05-25.png)

### 「VN状态」页：给 Ren'Py 的设定（偏专业化）

8. **变量 / 好感度**：定义状态机变量（支持数字、布尔、字符串，可关联角色）。这些变量会**写入 Agent 上下文**——比如设了「好感度」，Agent 就能按好感度高低写不同反应的戏。

9. **精灵（立绘与表情槽）**：定义角色立绘与每个表情（如 正常 / 开心 / 生气）的标签，Ren'Py 脚本中用 `show` 标签引用。对应关系在这里先约定好，写脚本时直接引用即可。

![image.png](/guide/05-26.png)




## 写作分析


分析是帮你发现问题、保持手感的工具。入口有两处：「项目 → 写作统计」看数据，「写作页 → 分析」（或「项目 → 结构分析」）看结构。粗讲都没提，这里全过一遍。



**「项目 → 写作统计」：三块数据**

1. **顶部三张卡：**总字数（附行数）、章节数（附平均字/章）、近 30 天写作（有多少天有产出）。字数超过一万自动显示成"X.X万"，不用自己数。

2. **近 30 天热力图：**一排小格，一格一天，颜色越深当天写得越多（按净增字数算）。注意它统计的是净增——今天删了 500 字又加了 800，就是 +300 的浅格。日常小幅改动会累积成浅格，别以为没写。

3. **章节字数表：**每章的字数、行数、对话占比、出场角色。对话占比能快速看出哪些章全是旁白、哪些章全是嘴炮；出场角色列是自动统计的（谁在本章说过话）。

![image.png](/guide/06-27.png)

**「写作页 → 分析」：七个子页**

4. **分支树：**根据章节里的 label / menu / jump 自动生成，一眼看清本章有几个选项、每条线通向哪。不需要你手动整理，纯自动。

![image.png](/guide/06-28.png)

5. **角色关系：**画布上每个角色一个点，关系线带标签。可以手动添加关系（角色 A — 关系标签 → 角色 B），也可以靠扫描自动生成候选。带 `?` 虚线的关系是"待复核"——说明出处可能漂移了，需要你确认。

![image.png](/guide/06-29.png)

6. **时间线：**按顺序排的时间节点，每节点有标题、时间标注、摘要。可以手动「添加时间节点」，扫描也会自动生成候选。写长篇时这里是防止"上一章说三年前、下一章变成五年前"的对照表。

![image.png](/guide/06-30.png)

7. **语气检查：**点「生成语气一致性报告」，AI 按角色卡里的语气设定检查当前章对白，找出"破人设"的台词（比如冷面角色突然话痨），逐条给严重程度、原文引用和修改建议。注意：这个报告只读，不写入关系图 / 时间线，看完心里有数就行。

![image.png](/guide/06-31.png)

8. **一致性审计：**全书层的检查——以角色卡 / 设定库 / 地图 / 时间线为权威，通读所有章节，找出设定违反和章节间矛盾。结果按 角色 / 时间线 / 地点 / 设定 / 书写 / 剧情 分类，标高 / 中 / 低严重度，并列出涉及章节。审计框里还能填关键词聚焦，比如输入「角色年龄」只查年龄问题。

![image.png](/guide/06-32.png)

9. **弧线：**角色出场热度曲线——横轴是章节，纵轴是每章对白行数，一条线一个角色。线突然掉到 0 就是角色"掉线"了，适合检查主角是否在某段消失太久；时间线事件也会标出角色关键节点。

![image.png](/guide/06-33.png)

10. **文风记忆：**让 AI 通读你的全文，归纳"你习惯怎么写"——句式节奏、用词、对白风格、应避免的套话。归纳结果注入 Agent 上下文，之后续写 / 改写 / 润色都会贴合你自己的文风，而不是 AI 腔。写几章后点「从全文学习文风」，不满意可「清除记忆」重学。

![image.png](/guide/06-34.png)

**顶部的一排扫描按钮（各子页通用）**

11. **扫描更新 / 全量扫描：**从剧本、圣经、角色卡里提取"事实"（角色关系、时间线候选），进入待审托盘。普通扫描只查增量，全量扫描忽略增量指纹重扫一遍。扫描完打开托盘逐条接受 / 拒绝——接受的关系和时间线才会写入角色关系页和时间线页。有变更时顶部会自动提示你扫描。

12. **待复核：**当某条已接受事实的原文出处被改动，它会变成"待复核"（虚线 + `?`），提醒你确认它是否还成立；「确认仍有效」可批量清除标记。

![image.png](/guide/06-35.png)

## 审稿 Agent


审稿 Agent 是写作页右下角那个浮动小窗——你在这站里的 AI 责编。它不只能聊天，还能改稿、做头脑风暴、整理关系、跑流水线。这章按"从打开到进阶"的顺序讲。

**30 秒快速上手**

1. 点顶栏「审稿」打开右下角面板

2. 选中稿子里一段文字，说「帮我润色这段」

3. 弹出左右对照，满意点写入，不满意点丢弃

#### 一、先认识界面

1. 打开：顶栏「审稿」按钮永远在——万一你把浮动窗拖丢了、或收起成了贴边标签，点它就能找回来。贴边标签点一下展开，按住可拖到屏幕任意边缘。

![test.jpg](/guide/07-36.jpg)

2. 窗口操作：面板可以拖动、拉右下角缩放、点「—」收成贴边标签、点「□」放大居中、点「↘」回右下角。手机上它是屏幕侧边的贴片。

![test.jpg](/guide/07-37.jpg)

3. 顶部三个小按钮：会话记录——左侧的对话列表，多场讨论分开存（可新建、改名、删除、拖宽度）；⇄——切换作家参谋；!——功能说明，含推荐流程。

#### 二、日常怎么用

4. 用平常话说：「改这一章更有人味」「把第三章对白再润一润」「别动某某角色」「整理关系进待审」。它听得懂的大致有：讨论、续写、改写、润色、分支、大纲、语气、查矛盾、写一场戏——不用记命令，说人话就行。输入框回车发送、Shift+回车换行。

5. 选区：选中稿子里一段文字再叫它，输入框下方会显示「选区 N 字」，它默认针对这段干活。

6. 附件：输入框旁 📎 可上传参考资料（txt / md / docx / json / csv / rpy），比如发一份设定文档，说「根据附件更新设定」；传完还能让它「按附件整理关系与时间线」。

7. 只给意见：不想让它动稿时，先强调「先不要改工程，只给意见」，它就只聊不动。

#### 三、换参谋：为什么换，怎么换

8. 默认的「通用文学编辑」已经很能打：轻小说 / 视觉小说写法底盘——可演对白、信息残缺、场钩子、类型热度，每次对话自动生效。日常改稿、润色、续写、查矛盾不用换任何人。切换是可选项：觉得默认反馈不够对味、想借特定写法传统的眼光时才换。

9. 换参谋 = 换一副看稿的眼光：点 ⇄ 打开参谋档案，一排作家卡，每张卡是一套公开写作技法的启发视角（非作家本人，禁止仿写原文）。它改变的不是聊天对象，而是后续对话里 Agent 参照的写法视角。内置 15 位，主要风格如下：

    |    风格类型|    特点关键词|
    |---|---|
    |    文学 / 氛围|    疏离日常、都市孤独、留白、克制比喻|
    |    悬疑 / 社会派|    公平伏笔、误导动机、因果收束|
    |    轻小说 · 学园恋爱|    别扭青春、心理防线、自欺、毒舌距离感|
    |    轻小说 · 对白密集|    靠嘴推进、口癖声纹、抬杠逻辑、定义权争夺|
    |    视觉小说 · 泣きゲー|    催泪向、长蓄力、一句决堤、静场余韵|
    |    视觉小说 · 致郁思想剧|    信念对撞、残酷有逻辑、改写立场的反转|

![test.jpg](/guide/07-38.jpg)

10. 怎么切：默认单选——点一张卡它就成为"对话中"视角，弹层关闭，此后对话都按它的眼光走；再点一次同一张卡 = 取消，回到通用编辑（点最上面那张「通用文学编辑」也一样）。换完下一条消息就生效，不用重开对话；每个项目的选择是独立的，不串剧本。

11. 冲突优先级是硬性约定：风格硬规则 > 通用编辑 > 所选作家视角——换视角不会压过你自己定的设定规则。

#### 四、头脑风暴：真正的分视角圆桌

11. 它和"一次对话里塞多个视角"是两回事：勾选「多选」后，同时选 2～3 位作家"入队"，填个议题（如「下一场如何升温」，可留空，留空就让它就当前章节和选区各自给建议），点「开始头脑风暴」。程序让每位作家各自独立调用一次模型——互相看不见对方的回答——全部完成后，责编（通用编辑主持）综合各家分歧，给出共识和三步行动建议。

12. 结果怎么看：完成后消息末尾显示「头脑风暴完成 · X/Y 视角」（Y 是你选的人数，X 是成功返回的视角数；个别模型调用失败时 X 会小于 Y）。正文通常有"各视角观点"和"责编综合"两段。

13. 快捷触发：直接在输入框说「头脑风暴：下一场怎么拆」也行——它会自动打开多选提醒你先选人。选人这步不能跳过：头脑风暴的前提就是至少两位独立视角。

#### 五、改稿与对照

14. 改稿对照：让 Agent 改章时，它先产出改稿草稿并弹对照，左右对比原稿 / 改稿，满意再写入，不想要就丢弃。草稿存在本地，刷新页面不丢，写作页工具栏「改稿对照」随时能再打开。

15. 撤回编辑：每次 Agent 写入后，消息下方会出现「撤回编辑（N 步）」——写坏了可按对话回滚，只撤它这次的动作，不动你手动改的东西。

#### 六、进阶：流水线、断点、纪律

16. 跑流水线：没思路或要一整场戏时，说「跑流水线：……」，它按 幕拆解 → 分步写作 → 声线检查 → 门禁（检查是否违反设定和风格规则）→ 记账（记录本次改动到变更日志）跑完整场。这是给"整场戏"的重活，不是日常必经步骤；日常聊天改稿不用它。

17. 断点续跑：长任务中断或出错时，会显示「上次运行中断（已完成 X/Y 步）」，点「继续上次运行」接着跑，不重复已完成步骤。

18. 定稿纪律（在 ! 功能说明面板里）：三项进阶开关——声线硬门禁（发现破人设等高危问题时直接阻止定稿）、终检声线（流水线最后一轮自动跑角色声线检查）、修正轮次（定稿前最多允许修正几轮）。默认值已经够用，普通用户不用动，想精细控制再调。

#### 七、几个小提醒

19. 它读得到什么：当前章、角色卡、设定库、地图、时间线、已接受的设定卡、文风记忆。设定写得越全它越懂你——前面"设定构建"那章不是白做的。

20. 它读不到什么：其他未打开的剧本、你没写进设定库的私设。需要它参考的内容，要么写进设定库，要么用附件上传。


## 导出与分享



稿子写完要见人：投稿要 Word / Markdown，试玩要 Ren'Py 工程，给画师配音看设定要只读链接，给自己留底要快照和工程 JSON。这章讲清楚每种格式什么时候用、从哪里拿。

#### 一、两个导出入口

1. 顶栏「导出」按钮 = 导出你眼前这份：看剧本稿就导出 .docx，看 RPY 稿就导出 .rpy，永远跟着当前视图走，适合"赶紧把正在写的这章弄出去"。

![test.jpg](/guide/08-39.jpg)

2. 「项目 → 导出」页 = 完整导出中心：下面所有格式都在这里，一次拿全。

![test.jpg](/guide/08-40.jpg)

#### 二、六种格式：操作 + 用途速查

先看表，再读细节：

|我要…|用什么|在哪拿|操作|
|---|---|---|---|
|投稿给编辑 / 平台|Word（.docx）|导出页 / 顶栏|一键下载|
|要 md 源的平台 / 留档|Markdown|导出页|一键下载|
|跑起来试玩 / 发给别人跑|Ren'Py 项目包（zip）|导出页|一键下载（要等打包）|
|备份留底|工程 .json|导出页|一键下载|
|只要单章脚本|.rpy|导出页 / 顶栏|先「生成」→ 再「下载」|

3. 生成 .rpy → 下载 .rpy（两步）：点「生成 .rpy」，把当前剧本转成脚本并显示在页面里供你检查；确认没问题再点「下载 .rpy」拿文件。注意：生成后如果又改了剧本，预览会标记过期——提示"剧本已改动，请重新生成"，别拿旧脚本去用。

4. 下载 Word（.docx）：一键下载，无需先生成。服务端直接产出投稿用的文稿，排版干净，能直接交。顶栏在剧本视图时按的就是这个。

5. 下载 Markdown：一键下载，无需先生成。给需要 md 源的平台，或自己留档。

6. 下载工程 .json：一键下载，无需先生成。整个项目的完整数据（章节、角色、设定、地图、变量全在里面）——最重要的留底格式，备份、迁移、以后导入回来都靠它。

7. 下载 Ren'Py 项目包（zip）：一键下载，无需先生成。完整可运行的 Ren'Py 工程骨架（script / options / gui / README 打包），不只是 .rpy 文本——要真正跑起来试玩、或发给别人跑，用这个。打包要一会儿，按钮会显示"打包中…"。

（和上面不重复的一点）顶栏导出的 .docx / .rpy 与第 1、2 条是同一套东西，只是入口不同：顶栏按视图走，导出页按格式走。

#### 三、只读分享：给"不用登录"的人看

8. 适用场景：画师看角色设定、配音对语气、朋友先睹为快——他们不需要注册，打开链接就能看。入口在「项目 → 快照 / 分享」，点「生成并复制链接」，链接自动复制到剪贴板。

9. 分享页上有什么：一个清爽的只读发布页——标题、题材、分享时间、章节数 / 字数、一句话简介，然后是正文试读、世界观、背景 / 大纲、角色卡（含语气、关系）、地点、变量 / 好感度、立绘表情对照、章节一览。底部有"AI 生成内容请自行审稿"的声明。

10. 正文试读的规则（提前说清，避免误会）：试读是发布时自动生成的节选——从第一段有正文的章节开始，每章截取前 700 字，最多 8 章，每章可点击展开。也就是说：读者能看到开头几章的开头部分，看不到全文；作者目前不能手动指定节选范围，规则是固定的。想看全文，还是走导出给文件。

11. 随时可撤销：点「撤销分享」，链接立即失效。分享是一次性快照——撤销后再生成是新链接。

#### 四、快照：给自己的后悔药

12. 手动快照：「项目 → 快照 / 分享」里，写个备注（可选）点「保存当前快照」。大改稿之前存一份，写砸了「回退到此」一键还原；「对比当前」看这版和现在差在哪。

13. 自动备份：系统自动留档（列表里带 ⏱ 标记的就是）。每个项目快照保留最近 20 份，超出滚动淘汰。

14. 留底建议：云端数据库有服务器备份，但重要稿请再自己导出一份 JSON / Word——双保险。

#### 五、长程记忆

15. 「快照 / 分享」页顶部还有「长程章节记忆」：章节多起来后，点「归档长程记忆」把每 10 章压成一段连续性摘要，审稿 Agent 自动带着最新段落写，不怕忘前文。写短篇用不上。


## 设置


左下角的齿轮打开设置。粗讲只提了一句"换主题、填 Key"，这章把设置面板讲全——先认识它长什么样，再按需调。

#### 设置面板速览

设置面板是一个弹窗，分四个页签，各管一摊：

- 外观——主题、字号，以及桌宠 / 音乐条 / 点击特效这些趣味开关

- 背景——自定义壁纸和取景调整

- 用量——你消耗了多少模型额度

- 模型——最重要，填 AI 的钥匙（API Key）

![img1.png](/guide/09-41.png)

#### 30 秒快速配置（新用户先做这个）

刚注册进来，最少只需要 4 步就能开始写：

1. 打开设置 → 切到「模型」页签

2. 从预设下拉选一家厂商（如 DeepSeek 或智谱免费档）

3. 粘贴你的 API Key

4. 点「测试连接」看是否成功，然后「保存」

其余全是按需再调，不用一次弄完。

#### 一、外观页签

1. 主题：日间 / 夜间两档，点击即切换。

2. 全局字体大小：一个滑条，拖动时下面有实时预览（用稿子里的一句话试效果），调完点「恢复默认字号」可一键回 100%。

3. 桌宠：开关控制屏幕上的 Q 版小人。开启后它可以这样玩：

    - 点击——换心情冒泡

    - 双击——摸头

    - 右键——弹出菜单（回到编辑器 / 缩到角落 / 隐藏桌宠）

    - 拖动——摆放位置，位置自动记住。不想要就整个关掉。

4. 音乐播放条（开关）：开启后底部常驻播放条，关闭会立即停止播放并隐藏。

5. 音乐播放条（加歌）：点播放条上的「＋ 添加」搜索网易云 / 酷狗 / B站 的歌曲——面板里可切换平台、看结果列表，选中即入播放列表。歌词面板里可粘贴 LRC 歌词文本（[00:12.00]第一句歌词 这种格式）滚动显示。

6. 点击特效：点空白处的赛璐璐圆环 + 粒子小动画。纯视觉、不拦截点击，输入框里不会触发；不喜欢就关。

**注意（隐私）**：听歌用的 Cookie（平台播放所需的登录凭证）只存在你本机浏览器，不会上传。

#### 二、背景页签（自定义壁纸）

7. 导入图片：点「导入图片」选一张图，铺满工作室底层（所有页面统一生效）。本地保存，不会上传。

8. 取景调整：预览区里可以直接拖动图片调取景区，旁边三个滑条分别调缩放（50%–300%）、透明度（8%–85%）、可读性暗角（0–85%——壁纸太花时加暗角保证文字可读）。

9. 面板玻璃：有壁纸时才生效。三档：自动（日间→雾色玻璃、夜间→墨色玻璃，跟着主题走）、雾色玻璃、墨色玻璃。

10. 一键适配深色壁纸：壁纸偏暗时点这个，自动切到夜间主题 + 墨色玻璃 + 提高不透明度，省得手动调一堆。

11. 另外两个小按钮：「复位取景位置」把拖动过的图片回到居中；「清除背景」移除壁纸。

![image.png](/guide/09-42.png)

#### 三、用量页签

12. 显示今日和累计的模型消耗：调用次数、输入 tokens、输出 tokens、总 tokens（tokens ≈ AI 计量的"字数"，输入输出各算各的）。用量存在你的账号里，换台设备也能看到，有「刷新」按钮手动更新。

## 常见问题FAQ


### 账号与登录

**收不到注册验证邮件 / 忘记密码怎么办？**在登录页点「忘记密码」，或在注册页点「重发验证邮件」。先检查垃圾箱——QQ 邮箱有时会延迟或误判。邮件发件人为 noreply@vnscriptstudio.cn，可提前加白名单。

**换浏览器 / 设备后，Key 和设置不见了？**外观设置（主题、壁纸、字号）存在本机浏览器，不会随账号迁移；模型 Key 若选择账号存储则会跟随账号，本机存储则不会。换设备后重新填写一次 Key 即可。

### 写作与编辑器

**剧本和 RPY 是什么关系？**剧本是给人和 AI 看的自然语言稿；RPY 是 Ren'Py 引擎的脚本，试玩只认 RPY。两份稿件互不覆盖，切换「剧本 / RPY」标签都在。需要上演时切到 RPY 页，点「根据剧本生成」。

**点了「试玩本章」为什么是空的？**试玩读取的是 RPY 稿。如果你只在剧本模式写了自然语言，RPY 还是空的——系统会提醒你先「根据剧本生成」或手写脚本，然后自动切到 RPY 页。

**写着写着忘了保存，会丢吗？**不会。停笔一两秒后自动保存，无需手动操作。「更多 → 保存章节」是额外选项。重要稿件建议再导出一份 JSON / Word 双保险。

**全屏专注模式怎么退出？**按 Ctrl+\ 再按一次，或点专注计时条上的「退出」。浏览器的 Esc 退出全屏也有效——按 Esc 退出系统全屏后，专注界面会同步退出。

### AI 与审稿 Agent

**Agent 点了没反应 / 一直显示"正在检索设定"？**先检查「设置 → 模型」：Key 是否填写、是否已点「测试连接」。没有 Key 时走站方免费兜底模型（每日有限额），额度用完会一直转圈——填写自己的 Key 或等第二天即可，或换用预设里其他模型。

**Agent 把稿子改坏了，能回退吗？**能。改完后消息下方有「撤回编辑（N 步）」，可按对话回滚本次操作，不影响手动修改的内容。改稿草稿未写入前，也可直接「丢弃预览」。

**怎么让 Agent 只给意见、不动手？**先说明「先不要改工程，只给意见」，它就只讨论不修改稿件。

**换了一位作家参谋，风格太冲怎么办？**再点 ⇄，点同一张卡取消，或选回「通用文学编辑」。冲突优先级是硬性的：你的风格硬规则 ＞ 通用编辑 ＞ 作家视角——设定页里写死的规则不会被参谋覆盖。

### 数据与容量

**一个账号最多建多少个项目？**约 80 个。达到上限后需删除部分项目，或导出 JSON 归档后再删除。

**快照会一直保留吗？**每个项目保留最近 20 份，超出后滚动淘汰。需长期留底时，手动「保存当前快照」并导出 JSON / Word 双保险。

**云端数据会丢吗？**工程存储在云端数据库，服务器另有定时库备份。即便如此，重要稿件请自行导出一份 JSON / Word——这是你自己的双保险。

### 导出与分享

**分享链接有有效期吗？**默认不过期，直到你点「撤销分享」才失效。注意：撤销后旧链接立即失效，重新生成的是新链接。

**分享页的正文试读能看到多少？**自动节选：从第一段有正文的章节开始，每章前 700 字、最多 8 章。规则固定，作者目前不能手动指定范围。需查看全文请走导出文件。

**导出的 .rpy 和 Ren'Py 项目包有什么区别？**.rpy 只是脚本文本文件；项目包是完整可运行的工程骨架（含 script / options / gui / README 的 zip）。要跑起来试玩用项目包，只要单章脚本用 .rpy。

### 协作与其他

**怎么和别人一起写？**顶栏「协作」邀请成员（可编辑 / 只读两种角色）。同一章同时编辑会看到锁——等锁释放后再改，避免互相覆盖。批注在写作页章节下方。

**手机上有哪些入口是藏起来的？**手机版顶栏按钮收进「更多」菜单；审稿 Agent 是屏幕侧边贴片（不是右下角）；支持 PWA——浏览器弹「安装为应用」后可像原生 App 一样使用，还能离线打开写作页。

**音乐播放条搜不到歌？**确认在「＋ 添加」面板里切了正确的平台（网易云 / 酷狗 / B站），并已按提示导入该平台的 Cookie（只存你本机，不会上传）。没有 Cookie 时部分平台搜索会受限。

**免费兜底模型和正式 Key 有什么区别？**免费档每日有限额、可能撞上限流，适合先体验；正式 Key 用量走你自己的账户，额度、隐私、稳定性都可控。写作量上来后建议尽早换自己的 Key。
