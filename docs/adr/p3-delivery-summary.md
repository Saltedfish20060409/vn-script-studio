## 两处确认（产品提问 · 如实现状 · 本轮不改代码）

### 1. 有选区时，能否在气泡里改成「章末追加」？

**答：不能。选区存在且能在原文中命中时，轻确认「写入」强制「替换选区」；气泡上没有作用域切换控件。**

推断规则（`handleConfirmWriteDraft`）：

| 条件 | 写入行为 |
|------|----------|
| 有选区且选区出现在原文中 | **替换该选区**（强制，不可在气泡改） |
| 无选区（或选区未命中） | 默认 **章末追加**（若草稿看起来像整章重写则整章替换） |

因此 ADR §6「写入语义显式、默认智能推断**可改**」在 P3 **尚未完整落地**：语义有默认推断，但 **用户不能在气泡里改作用域**。缺口记入后续（建议 P4/P5 UX：气泡上显式切换「章末追加 / 替换选区 / 替换整章」）。

### 2. 软超时提示的「持久」是多久？会不会遮挡气泡？

**答：从收到 `soft_timeout` 事件起，持续显示到本轮流结束（完成 / 取消 / 出错）；不是「闪一次就消失」，也不是「用户点掉才消失」。**

- 清除时机：`runWriteChannel` 的 `finally`（`setSoftTimeoutHint(null)`），与 `busy` 结束绑定。
- 布局：独立状态行，位于 thinking / 取消按钮 **下方**、流式草稿气泡 **上方**；**不覆盖**草稿正文，不挡「写入 / 放弃」按钮（那些在流结束后的助手气泡上）。
