# 桌宠美术指南（画师参考版）

> 配套文件：`docs/mascot-pet-art-brief.md`（逐帧规格，帧数/停留时长/挂点定死，交稿前必读）
> 本文档回答三件事：**画谁**（角色设定卡）· **画成什么风格**（可选方案）· **每个动作画什么**（表现要点与常见错误）

---

## 0. 一句话概括

桌面宠物「雾岛雪菜（Q 版）」：一个会趴在写作框上、偷偷探头、被戳会吓一跳、困了会打瞌睡的小助手。需要交付的是**透明底 PNG 逐帧序列**，程序按帧号播放；你只画"姿势循环"，位移/镜像/对齐由程序做。

**关键约束（与 brief 一致）**：
- 透明底 PNG，无背景、无阴影底板（脚底淡投影可，但要切干净）
- 同一序列脚底挂点（`foot`）或坐点（`sit_contact`）左右位置固定，人物不漂移
- 循环动作最后一帧能自然接回第 01 帧
- 只画面朝右（文件名带 `_r`），朝左由程序镜像
- 帧数、停留时长、命名一律按 brief，不要自行加减

## 1. 角色设定卡：雾岛雪菜（Q 版）

**身份**：轻小说 / 视觉小说写作软件的看板娘 + 桌宠小助手。
**性格**：安静、细心、有点小傲娇；陪你写稿时很乖，被戳会炸毛，夸她会开心。
**说话方式**：短句、平静，偶尔毒舌一句然后自己先慌。

### 形象选项（画师可二选一或混搭，交付前确认一套）

| 部位 | 选项 A（推荐） | 选项 B（备选） |
|---|---|---|
| 发型 | 齐刘海 + 及肩短发，右侧一撮小呆毛 | 双马尾 / 双辫，发尾微翘 |
| 瞳色 | 深蓝紫（带高光） | 琥珀金 |
| 服装 | 白底水手服 + 深蓝领巾，短裙 | 深蓝制服外套 + 格子短裙 |
| 配饰 | 胸前小徽章 / 笔袋挂件 | 发带 + 手腕小铃铛 |

### 建议配色（Q 版要"干净、好认"，饱和度不要太高）

| 用途 | 参考色 |
|---|---|
| 发色 | `#46559a`（深蓝） |

### Q 版比例

- **标准 Q 版**：约 2.2 头身（头占画布高约 55%）—— 推荐，动作可读性好

## 2. 风格方案（和画师商定选一套）

> 四种方案帧数、动作集完全相同（P0 23 帧 + P1 19 帧 + P2 约 13 帧），区别在**造型复杂度**与**成本**。选定后全文沿用同一套，不要混搭。

### 方案 A：标准 Q 版（推荐，性价比最高）
- 2.2 头身，圆润轮廓，细描边（1.5–2px），干净平涂 + 少量明暗（一至两阶）
- 特点：可爱、耐看、动作可读性强，动画工作量适中
- 建议画布：全身 512×768 / 探头 384×384（与 brief 一致）
- 参考风格方向：**Nekopara 类 Q 版、吉伊卡哇式圆润造型**的简化处理

### 方案 B：超迷你 Q 版（更萌、更省）
- 1.6–2 头身，头更大、四肢更短、几乎无身体细节
- 特点：最萌、细节少 → 单帧绘制快，成本最低；但动作幅度要画得更大才看得清
- 建议画布：全身 512×768 可缩小到 400×600（程序会等比缩放，不影响挂点比例）
- 参考方向：**LINE 表情贴纸风、崩坏星穹铁道帕姆类**

### 方案 C：精修 Q 版（精致、成本高）
- 2.5–3 头身，保留发型层次、领结、裙褶等细节，柔和阴影 + 高光
- 特点：最精致、站桩最漂亮；但逐帧工作量明显上升，走路/反应帧要保持细节一致较难
- 建议画布：全身 512×768（必要时 640×960）
- 参考方向：**蔚蓝档案 Q 版立绘、原神 Q 版大头**的精细处理

### 方案 D：简笔线条风（风格化、辨识度最高）
- 1.5–2 头身，粗描边（2–3px）+ 扁平色块，无渐变
- 特点：强烈风格化、和编辑器 UI 的"纸感"很搭；单帧简单，但线条节奏要稳（粗细/圆角一致）
- 建议画布：全身 512×768（实际内容约占 70%，留白交给程序）
- 参考方向：**卡通贴纸、涂鸦日记风**

**给制作人的选择建议**：预算有限 → B；追求质感且预算充足 → C；想快速有辨识度 → D；平衡 → A。

## 3. 动作详解（每个动作画什么、注意什么）

> 逐帧"这一帧画什么 / 相对上一帧怎么变"请严格照 `brief` 的表。这里补充**角色表现要点**与**常见错误**，帮画师一次画对。

### P0-1 `breath_idle`（待机呼吸 · 4 帧 · 循环）—— 最重要，先画这套
- 表现要点：这是桌宠 90% 时间的姿态。要"活但不吵"——胸口/肩膀的起伏用**头高的 2–3%**即可，重点是**裙摆和发梢跟着微动**，让人感觉她在轻轻呼吸
- 常见错误：① 起伏太大像在跳；② 头乱点；③ 忘了裙摆/发梢的联动（画面会"僵"）
- 检查：把 4 帧叠一起，脚底不动，只有胸肩和布料在 2–3px 内浮动

### P0-2 `blink`（眨眼 · 3 帧 · 单次）
- 表现要点：身体 100% 复用 `breath_idle_01`，只动眼皮。半闭→全闭→半闭，全闭时可以是一条微弯的线
- 常见错误：眨眼时耸肩/歪头；闭眼后 03 帧画成全睁（程序会切回呼吸，全睁会和呼吸帧"跳"）

### P0-3 `walk_side_r`（侧向走 · 6 帧 · 循环 · 面朝右）
- 表现要点：**人在原地走，位移交给程序**。右脚接触→左脚路过→左脚落地→左脚接触→……经典 6 帧步循环。手臂和腿**反向摆动**（左腿前→右手前）
- 常见错误：① 整体往右平移（不要！）；② 脚不交替像飘行；③ 躯干左右晃出挂点
- 检查：06 帧接到 01 时，"踏"的一下是否自然；脚底是否始终贴着 `foot` 的水平线

### P0-4 `perch_top`（趴在文本框顶 · 2 帧 · 微循环）—— 桌宠主要姿态
- 表现要点：坐在"框顶线"上（线不画进图），**视线朝下看框里的字**（这是"陪你写稿"的核心姿态）；小腿自然下垂，一手扶框沿
- 02 帧只做极小的上身摇摆（3–5°）或眯眼，`sit_contact` 像素位置 ±2px 内不动
- 常见错误：头太大挡住表情；整个人在框顶左右走；摇摆幅度大得像要掉下去

### P0-5 `peek_over`（框后探头 · 4 帧 · 单次可停 03）—— 桌宠第二核心
- 表现要点：**躲在框后只露头**。01 只露发顶/眼睛上缘 → 02 探出眼鼻 → 03 标准探头（程序常停这帧）→ 04 微晃。头部**从画布下缘进入**，下半截透明
- 表情：默认脸带一点好奇，视线看下方（框内）
- 常见错误：02 和 03 构图跳变（必须是同一探出路径的三个位置，程序要倒放缩回）；探太多露出肩膀以上太多（会挡文字）

### P0-6 `peek_side_r`（框侧探头 · 4 帧 · 面朝右）
- 表现要点：从**画布右缘**探出半张脸看向左下方；03 是常停帧；04 微动（眨眼/轻点头）
- 常见错误：探出方向搞反（是向"框内"探，不是向右走）；头缩回（03→04 高度/左右锁死）

### P1 组
- **P1-1 `perch_side_r`（扶靠框侧 · 2 帧）**：站框外靠右沿，手扶框边（`hand_grip`），头转向框内看字；02 重心再靠一点 + 头更歪
- **P1-2 `peek_under`（框下探头 · 4 帧）**：从画布底边抬头向上看（仰视），像钻桌底；视线向上
- **P1-3 `hide_corner`（缩角落 · 1 帧）**：抱膝蜷坐，体积明显小于站立，脸可半埋膝盖只露眼睛；情绪偏"worry 或安静"，少占屏
- **P1-4 `slip_r`（滑步换位 · 4 帧 · 单次）**：不完整走路，一小步滑过去（蓄力→迈出→并脚→收势），用于"从站姿过渡到框边"
- **P1-5 `react_fluster`（慌乱 · 4 帧 · 单次）**：被戳的反应！01 察觉睁大眼 → 02 双手挡胸/后仰（峰值）→ 03 落地收手 → 04 余悸半笑。**这是"点击桌宠"的主反馈，要可爱不要夸张**
- **P1-6 `react_cheer`（庆祝 · 4 帧 · 单次）**：保存成功/被夸。01 嘴角上扬 → 02 双手举过头/握拳（可微跳）→ 03 落地 → 04 收势浅笑

### P2 组（有预算再做）
- **`fall_asleep`（打瞌睡 · 5 帧）**：接在坐框顶后，头一点一点→回弹→睡着（可接极轻呼吸）
- **`drag_held` + `drop_land`（被提起/放下）**：拖动桌宠时显示——被拎后颈四肢微收脚悬空（2 帧晃动）；放下时落地缓冲（3 帧）
- **`read_over_shoulder`（侧身偷看文稿 · 3 帧）**：侧站、头转向屏幕方向、一手托腮，极轻微循环

### 挂点（画布内坐标，可用隐藏图层标十字，导出删掉）

| 挂点 | 位置 | 用途 |
|---|---|---|
| `foot` | 画布水平中线、底边向上 48px（A 套） | 站立动作对齐地面 |
| `sit_contact` | 屁股/腿肚接触"框顶"的点（A 套约 50% 高度处） | 趴框顶对齐 |
| `hand_grip` | 手扶框边的点 | 扶靠对齐 |
| `head_center` | 双眼中点（B 套尽量居中） | 探头对齐 |

### 画布

- A 全身：512 × 768（若方案 B 用 400×600 请在 README 注明，程序等比缩放）
- B 探头：384 × 384

## 5. 交稿自检清单（每套动作交稿前过一遍）

1. **帧间变化**：从 01 看到最后一帧，能指出"哪里动了"，且与 brief 的"相对上一帧"一致
2. **循环接缝**：循环动作把最后一帧和 01 并排，过渡不生硬（呼吸/走路/坐框顶尤其）
3. **挂点稳定**：同一序列半透明叠加，脚底/坐点基本重合（±2px）
4. **命名与帧数**：文件名与 brief 的动作 id、帧号完全一致；帧数不多不少
5. **透明与切边**：无背景残留；脚底淡投影切干净；没有多余的空白大字/水印
6. **朝向**：文件名带 `_r` 的面朝右（朝左交给程序）

## 6. 参考建议（画师可参考）

- **动作参考动画**：Live2D 桌宠（如 Bongo Cat / 桌面精灵）的待机与反应节奏；吉卜力式"微小而丰富的动"（呼吸看胸肩、布料看裙摆）
- **Q 版造型参考**：Nekopara / 蔚蓝档案 / 崩坏星穹铁道帕姆的 Q 版处理
- **情绪参考**：P1-5 慌乱可参考 Vtuber 被突然呼叫的表情；P1-6 庆祝可参考"双手握拳小跳"
- **交付节奏建议**：先画 **breath_idle + blink + perch_top + peek_over**（P0 核心 4 套，程序立刻能用），再补 walk / 反应 / 其余；P2 最后
