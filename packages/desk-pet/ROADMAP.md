# 独立桌宠路线图

网站版结论不变：**写作工具里**好感 / 桌宠侧长期记忆 / 默认 LLM 台词 / 小游戏 / 多桌宠 —— 高成本低回报，不做。  
本文件只描述**独立产品**里这些能力如何做成体验优势，以及移动端前提。

## Phase 0 — 内核冻结（已完成于 Studio）

- 状态机、图集、喂食/玩耍、闲聊写作提醒、呼吸、后台停 RAF、nginx/SW 缓存规则
- 运行时体积约 **868 KB** WebP（已去掉未使用的 `feed_hold` / `play_hold` 单帧）
- 本包用 `sync-from-studio.ps1` 拉取纯逻辑

## Phase 1 — 独立壳 + 透明宿主

目标：能单独打开一只宠，背景透明，不依赖 Studio。

| 项 | 做法 |
|---|---|
| Web 壳 | 最小 Vite 应用：只挂 `PetSprite` + 本地状态 |
| 桌面浮层 | Tauri / Electron：无边框、透明、可选点击穿透 |
| 移动端 | Capacitor 或系统悬浮窗；**先竖屏单宠** |
| PetHost | 视口尺寸、安全区、存储、音频、是否可穿透 |
| 资源 | WebP + alpha；禁止烘焙不透明底 |

验收：PNG/WebP 棋盘格预览无灰底；Android 悬浮窗能看到桌面壁纸透过。

## Phase 2 — 陪伴循环（好感但不打卡）

| 项 | 做法 |
|---|---|
| 好感 | 内部 0–100；**UI 默认不显示数字**；只影响表情倾向与台词池权重 |
| 衰减 | 缓慢（天级），喂食 / 闲聊 / 小游戏轻量回补；禁止「每日登录 +10」 |
| 主动聊天 | 本地日程 + 安静时段；频率受 `wanderInterval` 同类设置约束 |

风险对冲：设置里一键「隐藏陪伴数值」；新装默认看不出 RPG 条。

## Phase 3 — 私有长期记忆

| 项 | 做法 |
|---|---|
| 存什么 | 称呼、作息偏好、讨厌的话题、最近玩过的游戏、用户自述的一两句 |
| 不存什么 | 账号密码、Studio 工程正文、未同意的麦克风原文 |
| 形态 | SQLite / IndexedDB 本地；导出加密包可选 |
| 与 LLM | 检索进 prompt 的只有用户勾选过的记忆条 |

Studio 的工程记忆**不复用**到这里，避免写作隐私串台。

## Phase 4 — LLM 台词（可选）

| 项 | 做法 |
|---|---|
| 默认 | 关；固定池永远可用 |
| 开启 | 用户粘贴 API key / 走自建代理 |
| 人设 | 「桌宠本人」，禁止冒充写作 Agent「搭档」口吻（与 Studio 相反） |
| 失败 | 超时 / 跑题 → 立刻回退固定池，气泡标明「离线句」 |

## Phase 5 — 交互小游戏

优先短局、单手、可秒退：

1. **扔球接球**（已有 play 四拍可扩）  
2. **吹泡泡**（触控滑动）  
3. **简易棋类**（三子棋级，非完整围棋）  
4. 以后再加节奏向小玩法  

规则：游戏中暂停「主动聊天」；结束回待机不超过 1 次点击。

## Phase 6 — 多桌宠（暂缓）

资源与状态成倍；在单宠记忆 / 游戏稳定前不做。

## 移动端注意

- 触控替代悬停；长按 ≈ 桌面右键菜单  
- 省电：后台只留闹钟级主动聊，不跑 RAF  
- 权限：悬浮窗 / 通知分平台说明；麦克风仅语音聊且可关  
- 包体：图集按需下载，首包只带 idle + face  

## 刻意不从 Studio 回灌的东西

- 默认打开 LLM  
- 可见好感条 / 每日打卡  
- 自动全屏小游戏  
- 把用户文稿当桌宠记忆
