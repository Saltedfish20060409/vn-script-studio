# Desk Pet（独立桌宠）

从 VN Script Studio 网站桌宠拆出的**产品线种子**：网站版继续当写作旁观看板娘；本包面向「可单独打磨的陪伴型桌宠」，并预留移动端 / 透明浮层 / 大模型对话等能力。

## 两套产品，两套边界

| | 网站桌宠（本仓库 `frontend/`） | 独立桌宠（本包） |
|---|---|---|
| 目标 | 陪写、不抢注意力 | 陪伴与互动本身就是产品 |
| 好感 / 打卡感 | **不做** | 可做，默认隐藏数值，绑喂食/闲聊 |
| 长期记忆 | 用工作室工程记忆，桌宠不另存 | **需要**本地私有记忆（习惯、称呼、忌口） |
| LLM 台词 | 规格可选项，默认关 | 可接用户自备 API，旁白人设独立 |
| 小游戏 | 不做（挡写作） | 可做（下棋、接球、吹泡泡…） |
| 多桌宠 | 不做 | 后期再议 |
| 背景 | 叠在编辑器上 | **透明背景**浮层 / 系统级叠加 |
| 平台 | 桌面浏览器 ≥768 | Web → Capacitor/Tauri → 原生壳 |

网站版已落地的低成本能力（状态机、图集、喂食/玩耍、闲聊写作提醒、呼吸、后台停 RAF）是本包的**共享内核**；高成本能力只在本包路线图里推进，**不要回灌进写作工作室默认体验**。

## 与 Studio 同步

```powershell
# 在仓库根目录
pwsh packages/desk-pet/sync-from-studio.ps1
```

只拷贝**无 React 宿主依赖**的纯模块；`QPet` / `PetSprite` 仍留在 Studio，待 Phase 1 再抽渲染层。

## 设计原则（独立产品）

1. **透明优先**：导出与预览一律保留 alpha；移动端用系统悬浮窗 / 画中画时背景必须可镂空。
2. **记忆本地、默认可清空**：长期记忆默认 on-device；云同步需显式同意。
3. **LLM 可选**：无 key 时走固定台词池；有 key 时人设是「桌宠本人」，不是 Studio 的写作搭档。
4. **游戏可退出一秒**：任何小游戏必须一键回待机，且默认不自动弹起。
5. **网站内核只进、不回**：Studio 继续保持「旁观、短句、不挡笔」。
